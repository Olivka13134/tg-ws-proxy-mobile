# TG WS Proxy на телефоне

Прокси работает прямо на телефоне. Telegram на этом же телефоне подключается к нему по адресу 127.0.0.1:1443. Интерфейс и настройки те же, что в Windows-версии.

## Android

### Установка

1. Перекинь `TgWsProxy.apk` на телефон любым способом: через Telegram «Избранное», по кабелю, через Google Диск.
2. Открой файл на телефоне. Android спросит разрешение на установку из этого источника (из Telegram, Файлов или браузера): нажми «Настройки» → включи «Разрешить из этого источника» → вернись назад → «Установить».
3. Если появится Google Play Защита («Приложение не проверено»), нажми «Подробнее» → «Всё равно установить». Это нормально для приложений не из Play Маркета.

### Первый запуск

1. Открой TG WS Proxy и разреши уведомления. Пока прокси включён, в шторке висит уведомление, без него Android выключит прокси в фоне.
2. Нажми «Включить».
3. Нажми «Разрешить» в блоке про батарею → «Разрешить». Без этого Android может усыплять прокси, когда экран выключен.
4. Нажми «Подключить в Telegram» → в Telegram «Подключить прокси».
5. Если хочешь, чтобы прокси включался сам после перезагрузки телефона, поставь галочку «Запускать при включении телефона» и нажми «Сохранить».

На Xiaomi, Huawei, Honor и Samsung есть дополнительные «убийцы» фоновых приложений. Если прокси отключается сам: Настройки → Приложения → TG WS Proxy → Батарея (Контроль активности) → «Нет ограничений». На Xiaomi ещё включи «Автозапуск».

### Обновление

Новый APK ставится поверх старого, настройки и secret сохраняются. Нужно, чтобы APK был подписан тем же ключом (`android/signing/tgwsproxy.jks` в исходниках).

## iPhone

Готового файла для iPhone нет: Apple разрешает ставить приложения не из App Store только после подписи твоим Apple ID, а собрать приложение можно только на Mac (или на Mac-сервере GitHub).

### Вариант A: есть Mac

1. Установи Xcode из App Store, открой его один раз и дождись установки компонентов.
2. Установи Homebrew: https://brew.sh (одна команда в Терминале).
3. Распакуй исходники, в Терминале выполни:
   ```
   cd путь/к/tg-ws-proxy-go/ios
   ./build_ios.sh
   ```
   Скрипт соберёт ядро и откроет проект в Xcode.
4. В Xcode: слева нажми на проект TgWsProxy → вкладка Signing & Capabilities → Team → Add an Account… → войди своим Apple ID → выбери «(Personal Team)».
5. Подключи iPhone кабелем, разблокируй, нажми «Доверять этому компьютеру». Вверху Xcode выбери свой iPhone и нажми ▶ (Run).
6. На iPhone (iOS 16 и новее): Настройки → Конфиденциальность и безопасность → Режим разработчика → включить, телефон перезагрузится.
7. На iPhone: Настройки → Основные → VPN и управление устройством → твой Apple ID → «Доверять».
8. Снова нажми ▶ в Xcode, приложение запустится.

### Вариант B: нет Mac (только Windows)

1. Создай на github.com публичный репозиторий и загрузи туда содержимое папки `tg-ws-proxy-go` (кнопка «uploading an existing file» или GitHub Desktop).
2. Вкладка Actions → «iOS unsigned IPA» → Run workflow. Через 10–15 минут скачай архив `TgWsProxy-unsigned-ipa` внизу страницы запуска и распакуй, внутри `TgWsProxy-unsigned.ipa`.
3. Установи на компьютер iTunes (с сайта Apple, не из Microsoft Store) и Sideloadly: https://sideloadly.io
4. Подключи iPhone кабелем, открой Sideloadly, перетащи туда `.ipa`, впиши свой Apple ID, нажми Start.
5. На iPhone включи Режим разработчика и доверь свой Apple ID, как в пунктах 6–7 варианта A.

### Ограничения бесплатного Apple ID

- Приложение работает 7 дней, потом iPhone перестаёт его запускать. Подпиши заново: снова ▶ в Xcode или Start в Sideloadly, настройки сохранятся. С платным аккаунтом разработчика ($99 в год) срок 1 год.
- Одновременно можно держать не больше 3 таких приложений.

### Как работает на iPhone

1. Открой TG WS Proxy → «Включить» → «Подключить в Telegram» → «Подключить прокси».
2. iOS усыпляет приложения в фоне. Чтобы прокси жил, пока открыт Telegram, приложение проигрывает тишину. Музыку и звук в других приложениях это не перебивает.
3. Если прокси всё же остановился (после звонка, или другое приложение забрало звук целиком), Telegram покажет «Соединение…». Просто открой TG WS Proxy на секунду, прокси включится снова.
