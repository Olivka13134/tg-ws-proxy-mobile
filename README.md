# TG WS Proxy (Go)

Переписанный на Go [Flowseal/tg-ws-proxy](https://github.com/Flowseal/tg-ws-proxy). Протокол, настройки, secret и ссылка `tg://proxy` те же, ядро новое.

## Запуск (Windows)

1. Закройте старый TgWsProxy (иконка в трее → Выход), чтобы освободить порт 1443.
2. Запустите `TgWsProxyGo_windows_x64.exe`. Если до этого стоял старый TgWsProxy, его настройки и secret перенесутся сами, и прокси, уже добавленный в Telegram, заработает без перенастройки.
3. Если это первая установка, нажмите «Да», откроется Telegram с кнопкой «Подключить прокси».

В трее: подключить в Telegram, скопировать ссылку, настройки (страница в браузере), перезапуск, лог, автозапуск.
Настройки и лог хранятся в `%APPDATA%\TgWsProxyGo\`. Если рядом с exe создать папку `TgWsProxyGo_data`, включится портативный режим.

## Что изменилось по сравнению с Python-версией

- **Зависшие соединения.** ТСПУ иногда замораживает соединение до Telegram: сокет жив, но данные не проходят. Старая версия этого не видит, и сообщения стоят «часиками», пока Telegram сам не сдастся (около 30 с). Новая версия следит за TCP-подтверждениями от сервера Telegram. Если данные не подтверждаются 5 секунд, соединение рвётся, и Telegram тут же переподключается на свежее соединение из пула. В тесте с эмуляцией такой блокировки сообщение ждало 5,1 с вместо 30 с.
- **Гонка маршрутов.** Если прямой WebSocket не отвечает за 1 с, параллельно стартуют CF-прокси, CF Worker и TCP, и побеждает самый быстрый. Раньше ждали полный таймаут 5 с, потом пробовали по одному. Когда прямой IP снова доступен, это видно сразу.
- **Пул соединений** держит прогретые соединения на каждый DC, сразу замечает, если Telegram закрыл простаивающий сокет, и обновляет их до таймаута Telegram (~90 с).
- **Меньше задержек под нагрузкой.** Нет GIL и asyncio, один проход шифрования на пакет, пакеты из буфера склеиваются в одну запись.

## Командная строка

Флаги как у `tg_ws_proxy.py` (`--port`, `--secret`, `--dc-ip`, `--cfproxy-domain`, `--cfproxy-worker-domain`, `--fake-tls-domain`, `--no-cfproxy`, `--pool-size`, `-v` …) плюс:

- `--stall-timeout 5`: через сколько секунд без подтверждений рвать соединение (0 = выкл.)
- `--fallback-head-ms 1000`: фора прямому WS перед параллельным запуском обходных путей
- `--no-tray`: режим приложения без иконки в трее (настройки из config.json)

## Телефоны

- `android/`: приложение для Android (Java + ядро через gomobile). Сборка: `android/build_android.sh` (нужны Android SDK и NDK).
- `ios/`: приложение для iPhone (SwiftUI + ядро через gomobile). Сборка на Mac: `ios/build_ios.sh`, без Mac: workflow `.github/workflows/ios-unsigned-ipa.yml`.
- Установка на телефон: [INSTALL_PHONE.md](INSTALL_PHONE.md).

## Сборка

```
go test ./...
GOOS=windows GOARCH=amd64 go build -trimpath -ldflags "-s -w -H windowsgui" -o TgWsProxyGo.exe ./cmd/tg-ws-proxy
```

Требования: Windows 10+, Linux (иконка в трее через StatusNotifier), macOS 11+ (без иконки в трее, настройки открываются в браузере).
